Arabic type specimen

Each card: headline 64 px bold (or the family's heaviest weight up to 700, no faux bold), Saudi-dialect line 40 px, body 16 px, and a price in Arabic-Indic and Western digits next to the vectorised SAMA riyal symbol. The symbol's height is set to the measured height of that font's digits (value shown beside the prices). All families are SIL OFL 1.1 from google/fonts.
